# 📚 zotero_reference_manager

Skill autónoma que consulta la biblioteca Zotero y genera citas y notas de literatura dentro de esta bóveda.

## Capacidades
- Búsqueda en biblioteca personal: papers, normas de diseño vial, manuales MTC, tesis de estabilidad de taludes.
- Generación de citas en **APA 7**, **ISO 690** y formato **MTC**.
- Creación de notas de literatura en Obsidian a partir de un documento de Zotero.
