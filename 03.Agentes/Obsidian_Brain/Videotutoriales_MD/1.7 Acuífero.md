# **ACUÍFERO** 

- Formación Geológica, grupo de formaciones o parte de una formación, capaz de acumular y permitir el flujo de una significativa cantidad de agua subterránea. 

- Se puede definir también como toda formación geológica que contiene la agua ocupando 

- totalidad de los vacíos y que la transmite de un punto a otro en cantidades suficientes para 

- permitir su desarrollo económico.

# **ACUÍFERO** 

- Si la capa impermeable forma una depresión, puede aparecer un lago subterráneo. En cambio, si la capa impermeable esta inclinada se puede formar un rio subterráneo. 

- Cuando una capa permeable esta dispuesta entre dos capas impermeables, forma lo que se denomina acuífero cautivo o confinado. En estas condiciones el agua esta sujeta a una presión considerable. Si por cualquier circunstancia se crea una fisura en la capa impermeable, 

- entonces el agua asciende rápidamente hasta el nivel freático para equilibrar las diferencias de presión. 



- Por su parte, si la capa permeable no encuentra límite mas que en profundidad, entonces se denomina acuífero libre.
