# **Prueba de normalidad de Kolmogorov-Smirnov (n>50)** 

**_Ejercicios_** 

**1. Determine si los datos de la variable Liderazgo pedagógico provienen de una distribución normal, si se tiene una muestra de tamaño 111. Solución** 

**Formulación de las hipótesis Nula (H0) y Alterna (H1) H0: Los datos de la variable liderazgo provienen de una distribución normal. H1: Los datos de la variable liderazgo no provienen de una distribución normal.** 





**Regla de decisión: Si el p ≥0,05 se concluye H0 Si el p < 0,05 se concluye H1** 



**Conclusión: Como el nivel de significancia asintótica bilateral obtenido (0,000) es menor al nivel de significación (α=0,050) entonces se rechaza H0, es decir se acepta que: Los datos de la variable liderazgo pedagógico no provienen de una distribución normal, por lo que en la prueba de hipótesis se debe utilizar una prueba no paramétrica.**
