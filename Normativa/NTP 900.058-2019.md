# NTP 900.058:2019 — Código de colores para el almacenamiento de residuos sólidos

Norma Técnica Peruana que estandariza el **código de colores** de los recipientes de almacenamiento de residuos, para facilitar la segregación en la fuente exigida por el [[D.L. 1278]].

## Código de colores

| Color | Categoría |
| :--- | :--- |
| Marrón | Residuos orgánicos (restos de alimentos, poda) |
| Verde | Vidrio |
| Azul | Papel y cartón |
| Blanco | Plástico |
| Amarillo | Metal |
| Negro | Residuos generales no aprovechables |
| Rojo | Residuos peligrosos |

## Aplicación en obra
Cada frente de trabajo y el almacén central deben contar con la batería de contenedores rotulados según este código, con señalización visible y capacitación al personal sobre la segregación correcta.
