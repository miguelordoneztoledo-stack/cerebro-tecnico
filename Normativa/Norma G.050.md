# Norma G.050 — Seguridad durante la Construcción

Norma del **Reglamento Nacional de Edificaciones (RNE)** que fija los requisitos mínimos de seguridad y salud aplicables a toda actividad de construcción: edificación, obras de infraestructura vial, montaje y desmontaje, y trabajos de mantenimiento.

## Contenidos clave
| Capítulo temático | Alcance |
| :--- | :--- |
| Plan de SST | Obligatorio, integrado al expediente y con costo en presupuesto |
| Comité técnico de SST | Conformación y funciones en obra |
| [[Equipos de Protección Individual]] | Dotación mínima obligatoria por tipo de trabajo |
| Protección colectiva | Barandas, redes, entibados — ver [[Protección Colectiva en Zanjas]] |
| Orden y limpieza | Condición permanente del frente de trabajo |
| Señalización temporal | Delimitación, desvíos y control de tránsito |
| Excavaciones | Taludes, entibados, accesos, acopios |
| Trabajos en altura | Arnés, línea de vida, puntos de anclaje |
| Instalaciones eléctricas temporales | Tableros, puesta a tierra, distancias mínimas |
| Maquinaria pesada | Operación, señalero, radio de giro |

## Punto crítico para expedientes
Las partidas de SST deben estar **presupuestadas de forma explícita y desagregada**, no diluidas en gastos generales. Es una observación recurrente en revisión de expedientes.
